# AI Development Workflow Lab

A project exploring multi-agent AI workflows for software development.

The main goal is to create specialized AI agents that collaborate during the development process: from learning and architecture design to implementation, code review, and documentation.

The iOS application is used as a practical playground where agents can apply modern software engineering principles and architectural patterns.

# AI Agents

- Teacher: Explains concepts and creates learning materials.
- Architect: Designs solutions and evaluates architectural decisions.
- Developer: Implements features and writes code.
- Reviewer: Reviews code quality and suggests improvements.
- Technical Writer: Maintains documentation and development history.

# Technologies

- LangGraph
- LangChain
- Ollama
- Local LLMs
- Swift
- SwiftUI

This project uses local AI models. Generated outputs may vary depending on the model configuration.

This project explores how AI agents can be used as specialized engineering collaborators while building a real iOS application.
